Open WK Autoloader Store on every PS5 boot.

Firmware that turns an ESP32-S3 or ESP32-S2 Mini into a USB keyboard that opens WK Autoloader Store on every PS5 boot. The board only sends key presses. It contains no exploit, hosts no pages and sends no payloads.

Download v1.0.1Source on GitHub

What it does

  • On every boot it waits 18.5 seconds, then presses LEFT and ENTER to open the Store tile, which launches WK Autoloader Store.
  • The key sequence is a plain text file you can edit.
  • Optional Wi-Fi setup page at http://10.1.1.1 from the AutoStore network.

Requirements

  • WK Autoloader Store installed on the PS5 (it replaces the Store tile).
  • A 2.4 GHz home Wi-Fi network; the PS5 on the same LAN (Wi-Fi or Ethernet).
  • Automatic login on the PS5 is recommended for hands-free boots.

ESP32-S2 Mini (Wemos/Lolin, 4 MB flash, 2 MB PSRAM)ESP32S2_Mini_Keyboard_WK_Autoloader_Store_V1.0.1.bin

ESP32-S3: the UART / COM port is for flashing and logs, the native USB port goes to the PS5. ESP32-S2 Mini has a single USB-C port used for both.

Install

  1. Download the .bin for your board from the v1.0.1 release.
  2. Flash it in Chrome or Edge with the Espressif web flasher: connect the board UART / COM port to the PC (not native USB), click Connect, choose the COM port, baud 921600, add the file at address 0x0 and click Program. It takes about 1 minute; success looks like Hash of data verified.
    ESP32-S2 Mini: enter flash mode first: hold 0, press and release RST, then release 0. Use baud 115200 and address 0x0. After Program finishes, press RST.
  3. Plug into the PS5. ESP32-S3: move the cable to the native USB port and plug that port into the PS5 (never the UART / COM port). ESP32-S2 Mini: plug its USB-C port into the PS5.
  4. Set up Wi-Fi from your phone or computer (not from the PS5): join AutoStore (password 12345678), open http://10.1.1.1 (http, not https), enter your home 2.4 GHz Wi-Fi name and password and save. Console IP and board IP are optional. The board reboots and joins your home network.
  5. Restart the PS5. Keep the PS5 on your home network (do not connect it to AutoStore). On the next console boot the board opens WK Autoloader Store.

The board runs on a restart or full power-on of the PS5. Waking from rest mode does not trigger it.

Flashing with esptool (advanced)

esptool.py --chip esp32s3 --port PORT --baud 921600 write_flash 0x0 ESP32S3_Keyboard_WK_Autoloader_Store_V1.0.1.bin

Key sequence

18.5 seconds after the board gets power it runs data/config/nav_sequence.txt once:

0.3 LEFT
0.3 ENTER

Each line is <delay_seconds> <KEY>; lines starting with # are comments. Supported keys: ENTER, ESC, BACKSPACE, TAB, SPACE, UP, DOWN, LEFT, RIGHT, PAGE_UP, PAGE_DOWN. If your Store tile is elsewhere, edit the file and upload the filesystem again with pio run -t uploadfs.

Troubleshooting

ProblemFix
Flasher cannot open the portUse the UART/COM port; install the CH343 driver if needed
Board does not join home Wi-FiUse a 2.4 GHz network; reopen http://10.1.1.1 and save again

Console is never foundSet the console IP on the setup page
